Components

Built for impact.

Every component is crafted to be felt, not just seen. Hover the cards. The visuals tell the story.

Magnetic Cursor

Ring follows with lag. Dot snaps to exact position. Add data-magnetic to any element to activate.

Pure JS 60fps

3D Card Tilt

±13° rotation via pointer tracking with smooth lerp. will-change managed automatically — GPU only when active.

CSS Transform Glassmorphism

Dark / Light Mode

CSS custom properties swap on data-theme. Zero flash — resolves before paint. OS-aware, persists to localStorage.

No FOUC OS-aware

Scroll Entrance

IntersectionObserver triggers fade, scale, and slide animations when elements enter viewport. Each fires once, then disconnects to free memory.

No scroll listenerMemory-safe
Accessibility

All effects respect prefers-reduced-motion. Cursor hides, animations skip, tilt disables — zero JS errors.

Get started

Two lines.
Any project.

Paste into your <head>. Every component, cursor, animation, and theme switch — instantly available.

index.html
<!-- Add to <head> -->
<link rel="stylesheet" href="https://pebble-ui-taupe.vercel.app/dist/pebble.css">
<script src="https://pebble-ui-taupe.vercel.app/dist/pebble.js" defer></script>
