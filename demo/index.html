Components

Cards that respond.

Hover to feel the 3D tilt. Each card tracks your pointer with smooth lerp — no jitter, no layout shifts.

Magnetic Cursor

Ring follows with lag. Dot snaps to exact position. Elements with data-magnetic pull the cursor toward them. GPU-only, zero layout thrash.

Pure JS 60fps

3D Card Tilt

±13° rotation via pointer tracking. will-change set only during animation, cleared when idle.

CSS Transform Glassmorphism

Dark / Light Mode

CSS custom properties swap on data-theme. No flash — theme resolves before paint. Persists to localStorage.

No FOUC OS-aware

Scroll Entrance

IntersectionObserver triggers animations when elements enter the viewport. Each fires once, then the observer disconnects to free memory.

No scroll listener

Reduced Motion

All effects respect prefers-reduced-motion. Cursor hides, animations skip, tilt disables — no JS errors, no layout jumps.

Accessible

Buttons that move.

Feedback

Toasts that inform.

Auto-dismiss with a progress track. Click to close early. Four semantic types — one API call.

  type: 'success',

  message: 'All changes saved.',
  duration: 4000
